# 扫雷 Minesweeper

一个使用 C++ 编写的控制台版扫雷。

## 项目介绍

这是一个练习 C++ 面向对象和基础算法的小项目

目前实现了: (按完成时间排序)

- 棋盘初始化
- 随机生成雷
- 计算周围雷数量
- 铲模式
- 空白区域自动展开
- 玩家输入坐标
- 胜负判断
- 旗模式
- chord 功能
- 重新开始
- 计时功能
- 清屏功能
- 延迟布雷

## 游戏说明

切换模式:
- 在输入坐标前，选择性输入"m"，切换模式

输入坐标格式：横坐标 纵坐标

首次操作：强制打开格子(确保安全)

插旗模式下：
- 未打开格子：插旗/切换问号/取消
- 已打开数字格：周围旗数等于数字时自动展开

揭开模式下：
- 未打开格子：直接打开格子
- 已打开格子：周围旗数等于数字时自动展开

默认模式：
- 揭开模式
- 可将 Minesweeper/src/main.cpp 中变量 flagMode 改为 true ,将默认模式改为插旗模式

### 学习收获

1. rand()生成随机数固定，需要使用随机种子。如: srand(time(nullptr));
2. 空白区域展开使用递归，需要防止重复访问。
3. 了解 rand + time 生成地伪随机数的局限性，并学习使用 C++ `<random>` 库中的随机数引擎替代。
4. 了解 enum class 三态标记的设计思路
5. 了解模板函数对多种类型的复用方式
6. 函数职责拆分：嵌套过深时拆函数比压嵌套更好
7. 引用传参避免对象拷贝
8. 接触 `<sstream>` 库中输入流，并用其重写输入逻辑
9. 了解 `<chrono>` 库中获取当前时间戳与计算时间戳差值的函数
10. 在 cin >> 读取后,缓冲区会留有未读入内容及换行符，在其后 getline(cin,line) 遇到 '\n' 会读到空行
应清除缓冲区。如：`std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');`
11. 了解到 EOF ,认识到 输入失败后循环输入逻辑 若没有 EOF 校验,输入 EOF 会导致死循环,了解解决方案及其原理
std::cin四状态good / eof / fail / bad,现用其二 fail / eof
