# 扫雷 Minesweeper

一个使用 C++ 编写的控制台版扫雷。

## 项目介绍

这是一个练习 C++ 面向对象和基础算法的小项目

目前实现了:

- 棋盘初始化
- 随机生成雷
- 计算周围雷数量
- 玩家输入坐标
- 铲、旗模式
- chord 功能
- 空白区域自动展开
- 胜负判断

## 游戏说明

每轮先输入模式（0=揭开，1=插旗），再输入坐标。

例如：
1 3 5
表示在插旗模式下操作第 3 列、第 5 行。

插旗模式下：
- 首次操作：打开格子
- 未打开格子：插旗/切换问号/取消
- 已打开数字格：周围旗数等于数字时自动展开

揭开模式下：
- 直接打开格子

### 学习收获

1. rand()生成随机数固定，需要使用随机种子。如: srand(time(nullptr));
2. 空白区域展开使用递归，需要防止重复访问。
3. 了解 rand + time 生成地伪随机数的局限性，并学习使用 C++ `<random>` 库中的随机数引擎替代。
4. 了解 enum class 三态标记的设计思路
5. 了解模板函数对多种类型的复用方式
6. 函数职责拆分：嵌套过深时拆函数比压嵌套更好
7. 引用传参避免对象拷贝
